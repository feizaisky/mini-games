# 极速跑酷 (Speed Run)

3D无尽跑酷游戏，使用 Three.js 构建。

## 玩法

- **左滑 / A键 / 左箭头**: 切换到左侧赛道
- **右滑 / D键 / 右箭头**: 切换到右侧赛道
- **上滑 / W键 / 上箭头 / 空格 / 点击**: 跳跃
- **下滑 / S键 / 下箭头**: 滑铲

## 障碍物

| 类型 | 描述 | 应对方式 |
|------|------|----------|
| 路障 | 红黄条纹低矮障碍 | 跳跃 |
| 高墙 | 青色顶部横梁 | 滑铲 |
| 车辆 | 紫色移动汽车 | 左右躲避 |

## 计分

- 距离分 = 距离 × 10
- 金币分 = 金币数 × 50
- 连续收集金币有连击加成

## 技术实现

- Three.js 3D 渲染
- 对象池复用障碍物和金币
- 触控手势识别
- 渐进式难度提升
