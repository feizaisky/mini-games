# 三消

交换相邻宝石，凑成三连或以上同色即可消除得分。

## 玩法

- 点击一颗宝石选中，再点击**相邻**的另一颗宝石交换。
- 若交换后能形成横或竖方向三个及以上同色，则消除并掉落补充，连续消除有连击加分。
- 若交换后无法形成三连，会自动换回。
- 每局 25 步，步数用尽后游戏结束，记录最高分。

## 本地运行

在项目根目录执行：

```bash
python3 -m http.server 8000
```

浏览器打开 `http://localhost:8000/match3/`。

## 存储

最高分保存在 `miniGames.v1.match3.best`（数字字符串）。
