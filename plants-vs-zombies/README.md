# 植物大战僵尸（Canvas 版）

单文件 Canvas 实现的迷你植物大战僵尸，无外部资源依赖，所有图形与音效均为运行时绘制/合成。

## 玩法

- 点击收集阳光，阳光够数后点卡片选植物，再点草地种植
- 植物：向日葵（产阳光）、豌豆射手、坚果墙、寒冰射手（减速）、双发射手、樱桃炸弹（清场）
- 僵尸：普通 / 路障 / 铁桶，撑过最后一波即胜利
- 铲子可移除植物；电脑数字键 1-6 选卡、P 暂停；手机触屏直接点按（竖屏自动旋转，横持游玩）

## 记录

- 最佳通关用时：`miniGames.v1.plants-vs-zombies.best`（秒）
- 静音状态与全站公共键 `gameAudioMuted` 同步

## 结构

- `index.html` — 页面骨架 + 样式
- `game.js` — 全部游戏逻辑（渲染、音效、输入）

音效为本游戏内置的 WebAudio 合成（SFX），未使用 `common/audio.js`，仅同步其静音状态；胜利时叠加 `common/celebration.js` 彩带动画。
