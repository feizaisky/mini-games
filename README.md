# 贪吃蛇游戏 🐍

一个简单有趣的贪吃蛇网页游戏

## 功能特点

- 🎮 流畅的游戏体验
- 🎨 精美的渐变色设计
- 📊 实时计分系统
- ⚡ 难度递增（吃到食物会加速）
- 👀 可爱的蛇眼和食物效果

## 如何运行

### 方法 1：直接在浏览器中打开

```bash
cd /root/clawd/snake-game
# 用浏览器打开 index.html 文件
```

### 方法 2：使用本地服务器

```bash
cd /root/clawd/snake-game
python3 -m http.server 8000
# 然后在浏览器访问 http://localhost:8000
```

## 游戏控制

- **↑** - 向上移动
- **↓** - 向下移动
- **←** - 向左移动
- **→** - 向右移动

## 游戏规则

1. 使用方向键控制蛇的移动
2. 吃到红色食物可以得分（每个 10 分）
3. 蛇会随着得分增加而变长
4. 撞到墙壁或自己身体，游戏结束
5. 每吃一个食物，蛇的速度会加快

## 技术栈

- HTML5 Canvas
- 原生 JavaScript
- CSS3 渐变和动画

## 文件结构

```
snake-game/
```

## 自定义

可以在 `game.js` 中修改以下参数：

```javascript
const gridSize = 20;           // 网格大小
const gameSpeed = 100;         // 初始游戏速度（毫秒）
// 可以修改颜色、大小等参数
```
