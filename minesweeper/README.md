# 扫雷

经典扫雷游戏，翻开所有非雷格即胜利。

## 玩法

- **点击**格子：翻开该格，显示周围雷数（或空白则自动翻开相邻）。
- **长按**或**标记模式 + 点击**：插旗/取消插旗，标记疑似地雷。
- 首次点击保证不会踩雷（此时才随机布雷）。
- 踩雷即失败；翻开全部非雷格即胜利，并记录该难度最佳用时。

## 难度

- 初级：9×9，10 雷
- 中级：11×12，18 雷
- 高级：11×18，35 雷（横向最多 11 格）

## 本地运行

在项目根目录执行：

```bash
python3 -m http.server 8000
```

浏览器打开 `http://localhost:8000/minesweeper/`。

## 存储

最佳用时按难度保存在 `miniGames.v1.minesweeper.best`（JSON：`{ easy, medium, hard }` 秒数）。
